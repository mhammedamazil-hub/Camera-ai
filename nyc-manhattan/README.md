# NYC — procedural Manhattan, golden hour

A cinematic 6-second shot of Manhattan at golden hour, built entirely in code with
[three.js](https://threejs.org) + [Remotion](https://remotion.dev) using the
[cinematic-3d](https://github.com/Asbeel24/cinematic3d) skill.

| | |
|---|---|
| Composition | `nyc-manhattan-16x9` |
| Format | 1920 × 1080, 24 fps, 144 frames (6 s) |
| Lens | 50 mm (27° vertical FOV) |
| Master | `out/nyc-manhattan-16x9.mp4` — H.264, CRF 18, yuv420p |
| Proxy | `out/nyc-manhattan-16x9-proxy.mp4` — 960 × 540, CRF 23 |
| Seed | `7` (fully deterministic) |

The camera sits 400 m above the West Side, south-west of the island, and performs a
single eased 200 m push-in while looking north-east across Midtown. Empire State
stands mid-right of frame, One Vanderbilt and 432 Park read at frame left, the
Chrysler crown catches the last light on the far right, and the Hudson, New Jersey
shore and the Bayonne bridge towers haze out at the left edge.

## What is actually in the scene

Everything is generated at real-world scale in metres from data tables in
`src/shot/Shot.tsx` (2023 lines, no external assets except generated canvas textures):

- **Manhattan street grid** — the avenue grid is rotated 29° (the true island
  bearing) and modelled block-by-block: 2–6 lots per block, plot sizes from the
  Manhattan zoning envelope, street walls with cornice parapets, and towers placed
  with a heat map that peaks in Midtown and the Financial District.
- **Landmarks** — a hand-placed table of the 25 tallest real towers (Empire State
  443 m, One Vanderbilt 490 m, Central Park Tower 472 m, 432 Park 426 m, Chrysler
  319 m with its stepped steel crown, One World Trade 541 m, 30 Rock, the Billionaires'
  Row pencil towers…) with correct footprints, heights and crown treatments.
- **Boroughs and region** — Brooklyn, Queens, Jersey City and the Palisades as
  distance-graded geometry, plus the Hudson and East River as reflective planes.
- **Street life** — Central Park canopy, roof water tanks, billboards, ferries on
  the Hudson, and cloud-shadow bands drifting over the grid.
- **Facades** — four procedural 512 px canvas textures (pre-war masonry, limestone,
  glass curtain wall, residential) tiled to 8 storeys, with 45 faint lit windows per
  tile so the skyline keeps its sparkle at dusk, and a baked-in grime gradient.
- **Grade** — 3400 K sun at 6.5° elevation, 10 800 K sky fill, warm 3500 K ground
  bounce, ACES tonemapping, bloom 0.17, halation 0.26, exposure 0.92, film grain and
  vignette. Aerial perspective comes from an exponential haze band
  (`exp(-h·26)`) tinted `#eec5a4` over a moonstone dome (`#2f639b` → `#c7c2ba`).

## Rendering

```bash
# one-time: ffmpeg + headless chromium (see ../tools/setup-toolchain.sh)
./tools/setup-toolchain.sh
export CINE_BROWSER=/opt/cine-browser/chrome-wrap CINE_GL=swangle
export LD_LIBRARY_PATH=/opt/cine-browser/lib

SKILL=~/.claude/skills/cinematic-3d
node $SKILL/scripts/doctor.mjs                     # environment check
node $SKILL/scripts/stills.mjs                     # 5 stills + review/contact.png
node $SKILL/scripts/render.mjs --proxy             # 960×540 review render
node $SKILL/scripts/render.mjs --final             # 1920×1080 master
```

`stills.mjs` is the gate: it fails the shot if more than 1 % of the frame is clipped
highlights or more than 3 % is crushed shadow. Current state — mean luma 0.553,
0 % clipped, 0 % crushed.

### Composing a new camera

Don't eyeball it. `tools/frame-check.mjs` projects the real landmarks to 1920×1080:

```bash
node tools/frame-check.mjs 50 -300 400 -2000 300 190 100
```

It prints screen position, height in pixels and CUT/BEHIND flags for each tower.
At 50 mm the view axis should pass roughly 1000–1100 m east of a landmark to push it
to the frame edge without cropping.

## Honest scope note

Manhattan has ~1.1 million buildings; this shot instantiates a few thousand of them,
with the real 25-landmark table, the real grid geometry and real district heat
distribution. It is a faithful *depiction* of the skyline seen from the West Side —
not a survey-grade 1:1 reconstruction of every building. Everything you see is
generated by the code in `src/shot/Shot.tsx`; no photogrammetry, no imported meshes.
